TurboWarp OpenAI Realtime

Talk with the OpenAI Realtime API by voice or text from TurboWarp, and let the model call functions written in blocks. The API key stays in a localhost relay.

Before you start

  1. Start @kubohiroya/capability-proxy on 127.0.0.1 with the openai provider configured. Note the eight-digit pairing code it prints.
  2. Load turbowarp-openai-realtime-api.js as a custom extension with Run without sandbox enabled.

First conversation

configure local relay [http://127.0.0.1:8787]
pair local relay with one-time code [12345678]
connect to Realtime with microphone [on]
send text [Hello!]

when assistant finishes responding
say (last assistant response)

Functions as tools

Write a define function script and choose export as tool. NAME, DESCRIPTION, and the JSON args schema must be typed directly into the hat. When the model calls the tool, read arguments with function argument and send the result with return.

define function [get_score] description [Returns the player's score.] args schema [{"type":"object","properties":{}}] export as [tool]
return (join [{"score":] (join (score) [}]))

Safety

  • The relay endpoint must be a loopback address. The relay token and ephemeral keys are kept in memory only.
  • The model chooses the arguments of exported functions. Treat them as untrusted input.
  • If something fails, check last Realtime error.
